# Bio-Tech Edu

Bem-vindo ao repositório do projeto Bio-Tech Edu, uma jornada interativa de aprendizado em biologia, química e ciências com foco em educação científica e engajamento dos estudantes.

## Visão geral

Este repositório reúne uma experiência educativa composta por:

- 8 cientistas brasileiras como mentoras;
- 8 missões interativas;
- dinâmica de "Fato ou Fake";
- simuladores de hibridação;
- nomeador IUPAC;
- metodologia Cornell Notes;
- desafios no estilo ENEM com feedback explicativo.

A proposta do projeto é tornar o conteúdo científico mais acessível, envolvente e didático, conectando teoria, prática e avaliação em uma experiência moderna.

## Objetivo

Promover uma aprendizagem ativa e contextualizada, estimulando a curiosidade dos estudantes por meio de atividades interativas, desafios e explicações claras sobre conceitos científicos.

## Tecnologias

O repositório possui uma estrutura baseada em HTML, sendo adequado para a criação e apresentação de uma experiência web educativa estática.

## Como visualizar o projeto

1. Clone este repositório:
   ```bash
   git clone https://github.com/Bio-Tech-Edu/org.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd org
   ```
3. Abra o arquivo `index.html` em um navegador, ou execute um servidor local para uma melhor experiência:
   ```bash
   python -m http.server 8000
   ```
4. Acesse no navegador:
   ```bash
   http://localhost:8000
   ```

## Estrutura do projeto

A estrutura pode variar conforme a evolução do projeto, mas a ideia central é manter o repositório organizado em páginas e recursos didáticos voltados à experiência interativa do Bio-Tech Edu.
