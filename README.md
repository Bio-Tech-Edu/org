## Visão geral

O Bio-Tech Edu é uma iniciativa de educação científica e tecnológica voltada para estudantes que desejam aprender ciência de forma mais envolvente, visual e interativa. O projeto combina conteúdos acadêmicos, jogos pedagógicos e metodologias de aprendizagem ativa para transformar a ciência em uma experiência mais acessível e estimulante.

A proposta central é aproximar os estudantes de temas como biologia, química e biotecnologia por meio de:

- narrativas interativas;
- desafios com feedback explicativo;
- dinâmicas de investigação e raciocínio;
- ferramentas de simulação e resolução de problemas;
- metodologia de estudo estruturada para reforçar a aprendizagem.

## Missão pedagógica

Promover uma aprendizagem significativa, interdisciplinar e motivadora, conectando ciência, educação e tecnologia. O projeto busca fortalecer a curiosidade, a autonomia e a compreensão crítica dos estudantes por meio de experiências imersivas e conteúdo de alta qualidade.

## Objetivo do projeto

- estimular o interesse por áreas científicas;
- facilitar a compreensão de conceitos complexos;
- aproximar estudantes de referenciais científicos nacionais;
- criar uma experiência educacional acessível e envolvente;
- oferecer desafios de nível acadêmico em um formato dinâmico e didático.

## Features

- 8 missões interativas com narrativa e progressão;
- mentoras científicas com destaque para a atuação feminina na ciência;
- dinâmica de Fato ou Fake para reforçar o pensamento crítico;
- simuladores de hibridação para explorações práticas;
- nomeador IUPAC para reforçar linguagem e regras químicas;
- Cornell Notes como suporte para organização e revisão;
- desafios estilo ENEM com correção e feedback explicativo;
- abordagem interativa e visual para facilitar a aprendizagem.

## Instruções básicas de visualização

1. Clone o repositório:

```bash
git clone https://github.com/Bio-Tech-Edu/org.git
```

2. Acesse a pasta do projeto:

```bash
cd org
```

3. Abra o arquivo `index.html` diretamente no navegador ou use um servidor local:

```bash
python -m http.server 8000
```

4. Acesse:

```bash
http://localhost:8000
```

## Roadmap

### Fase 1 — Base da experiência
- estrutura inicial do projeto;
- organização do conteúdo e navegação;
- apresentação das missões e mentoras;
- criação da identidade visual elementar.

### Fase 2 — Interatividade
- desenvolvimento da dinâmica Fato ou Fake;
- criação de simuladores de hibridação;
- implementação do nomeador IUPAC;
- refinamento das telas e fluxos didáticos.

### Fase 3 — Aprendizagem e avaliação
- integração de desafios estilo ENEM;
- feedback explicativo sobre erros e acertos;
- aprimoramento da experiência de estudo com Cornell Notes;
- consolidação de materiais de apoio.

### Fase 4 — Expansão e disseminação
- mapa de conteúdos e trilhas de aprendizagem;
- divulgação institucional e pública;
- apoio à comunidade educativa e às escolas;
- melhoria contínua com base em feedback de usuários.
